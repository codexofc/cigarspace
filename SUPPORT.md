# Getting Help

Thank you for using **Cigarspace**. The fastest way to get help depends
on what you need:

## Questions, ideas, show-and-tell

→ Open a thread in **[GitHub Discussions]**. This is the right channel
for usage questions, design ideas, schema clarifications, and showing
what you have built on top of the platform.

## Bug reports

→ Open an **[issue]** using the **Bug report** template. Include:

- a minimal reproducer (curl, snippet, screenshot),
- the version (`git rev-parse HEAD` or release tag),
- runtime details (Python, Node, Docker versions, OS),
- redacted logs.

## Feature requests

→ Open an **[issue]** using the **Feature request** template. Explain
the use case and the workaround you currently use (if any).

## Security issues

→ **Do not** open a public issue. See [SECURITY.md](./SECURITY.md) for
the private reporting channel.

## Commercial use

The default license is non-commercial. For commercial deployments,
hosted offerings, OEM bundling, or paid support, see
[COMMERCIAL_LICENSE.md](./COMMERCIAL_LICENSE.md).

## Response expectations

Cigarspace is maintained on a best-effort basis. There is no SLA on
Discussions or community issues. Security reports are acknowledged
within a reasonable timeframe — see [SECURITY.md](./SECURITY.md).
