Cigarspace is released under the [PolyForm Noncommercial 1.0.0](./LICENSE)
license. This means you are free to use, modify, and redistribute the
software for **non-commercial purposes**: personal study, research, hobby
projects, internal evaluation, educational use, and contributions back to
the project.

If your intended use is **commercial** — even partly — you need a separate
commercial license from the copyright holder before you ship.

## What counts as commercial use?

The PolyForm Noncommercial license treats as commercial any use that has an
anticipated commercial application. Concrete examples we treat as
requiring a commercial license:

| Scenario                                                                | Needs commercial license? |
| ----------------------------------------------------------------------- | ------------------------- |
| You browse / fork / read the source                                     | No                        |
| You run Cigarspace locally to learn or experiment                       | No                        |
| You contribute patches via Pull Request                                 | No                        |
| A university lab uses it for research                                   | No                        |
| You sell access to the software (SaaS, hosted product)                  | **Yes**                   |
| You bundle Cigarspace inside a product your company sells               | **Yes**                   |
| You use Cigarspace internally for revenue-generating operations         | **Yes**                   |
| You provide paid consulting that requires deploying Cigarspace          | **Yes**                   |

When in doubt, get in touch — we'd rather have an honest conversation than
a misunderstanding.

## How to request a commercial license

1. **Email** `Michon.arthurperso@gmail.com` with subject
   `Cigarspace · Commercial License Request`.
2. Tell us briefly:
   - Who you are (individual / company name, country).
   - What you intend to build / how Cigarspace fits in.
   - Expected scale: number of users, environments, deployment model
     (on-premise, SaaS, embedded…).
   - Any specific terms you need (audit rights, support SLA, indemnity,
     OEM resale, etc.).
3. We'll come back to you with terms, typically within one week. Pricing is
   case-by-case and depends on use, scale, and the support level you need.

## What we never do

- We do not charge anyone for the source code itself — it stays available.
- We do not retroactively gate features behind a license check inside the
  software. Commercial licensees get the same artifact as everyone else,
  plus the legal right to use it commercially.
- We do not require attribution beyond the `Required Notice:` clause
  embedded in the PolyForm license.
